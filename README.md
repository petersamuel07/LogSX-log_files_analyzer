# Log File Analyzer

A production-style ETL and analytics pipeline that parses application log files, stores them in PostgreSQL via SQLAlchemy, and produces statistical analysis, charts, and CSV/JSON reports.

> **Status:** Under active development — built step by step. Full documentation (architecture, ER diagram, installation guide, example outputs) lands in the final step.

## Tech Stack

Python 3.13 · PostgreSQL 17 · SQLAlchemy · Pandas · NumPy · SciPy · Matplotlib · pytest
